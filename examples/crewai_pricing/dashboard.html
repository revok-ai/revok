Demo Setup — run these steps in order to see the drift problem

1
Train agents on current pricing
Stores the current database price ($500/mo) into each agent's long-term memory via Mem0. Both agents now "know" the price. Confidence starts fresh — no CDC events have fired yet.
2
Simulate a price change
Updates the operational database — as if the vendor raised prices. The agents' memories still say the old price. This is the moment drift begins.
New price: $
3
Fire a CDC signal
Simulates a downstream event (webhook, CDC pipeline) notifying the with-Revok agent that pricing data changed. Revok intercepts the write, detects the entity, and degrades confidence immediately. The without-Revok agent receives no event — its memory stays unchanged.
Now ask both agents a question
The without-Revok agent answers from memory blindly. The with-Revok agent checks confidence first — if it's stale, it re-verifies against the live database before answering.
Try asking after step 1 (fresh memory) and again after step 3 (drifted memory) to see the difference.
